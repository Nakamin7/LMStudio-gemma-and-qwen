# UIからモデルを切り替える

1. LM StudioでAPIサーバーを起動し、利用したいGGUFモデルをダウンロード済みにする。
2. `start_worker.bat` を停止し、進行中のチャットがないことを確認する。
3. `start_ui.bat` を起動し、`Model Connection` タブを開く。
4. 「モデル一覧を更新」を押し、モデルを選択する。
5. コンテキスト長は初回2048、KVキャッシュGPUはOFFを推奨する。
6. 確認チェックを入れ、「選択したモデルに切り替える」を押す。
7. 成功表示後にワーカーを再起動する。

モデル切り替えは LM Studio Native REST API `/api/v1/models`、`/load`、`/unload` を利用する。既存のLLMをアンロードした後、対象モデルをロードするため、ロード失敗時はモデル未ロード状態になる場合がある。メモリ保護設定は変更しない。UIでの選択結果はローカルの `model_selection.sqlite3` に保存し、チャットとワーカーで共有する。`.env` の `LM_STUDIO_MODEL` は、選択情報がない場合のフォールバック。複数同時推論・別プロセスでのモデル切り替えを自動調停する機能はないため、切り替え中はワーカーを停止する。

モデルが一覧に表示されない場合、LM Studioのダウンロード状況とAPIサーバーの状態を確認する。ロード時にメモリ不足となる場合、コンテキスト長を下げる、LM Studio側のオフロード設定を調整する。GPUオフロード率の直接変更は本UIでは未対応。
